# OpenCV를 통해 구현한 비디오 플레이어.

## Rationale

업무 중, 옆 팀에서 여러 영상을 동시에 틀어야 하는 소요가 발생했다. 마침 작업이 끝난 참이라 mp4도 학습할 겸, 멀티뷰 영상 플레이어를 만들어보려 한다.

**목표:** 과연 몇개의 영상 동시 재생까지 내 컴퓨터가 버틸지 측정하기

## Simple View Player

처음에는 OpenCV를 이용해서 비디오 플레이어를 만들려고 했다.

### OpenCV는 비디어 플레이어 만들기에 적합하지 않다.
문제: OpenCV는 사운드 재생을 못 한다...

OpenCV와 다른 사운드 재생 라이브러리를 이용해서 사운드 재생을 할 수는 있다.
하지만, 여러 문제가 있다.

1. 비디오영상을 위해서 한번, 사운드 재생을 위해서 한번. 총 2번 비디오 파일을 읽어야하는 문제.
2. 비디오랑 사운드 싱크를 맞추기가 너무 힘들다.

그래서 결국 OpenCV가 내부에서 이용하는 FFmpeg를 이용해서 비디오와 사운드를 동시에 재생하는 방법을 찾았다.

### FFmpeg는 너무 로우레벨이다.

또 다른 문제: FFMpeg는 너무 로우레벨이라 이걸로 개발하면 한참 걸린다. 

해결법: 고수준의 라이브러리인 LibVLC를 이용해서 FFmpeg를 쉽게 사용할 수 있다.

## LibVLC MultiView Player

LibVLC를 이용해서 만들었고, 16개 영상을 동시 재생할 수 있도록 했다.

### 문제
16개 중-고화질 영상을 동시 재생하니, 이거 생각 이상으로 리소스를 많이 잡아먹는다.

1. 램을 3.3기가를 잡아먹는다.
2. GPU를 100% 잡아먹는다.

즉, 리소스 활용도가 너무 낮다.

### 생각한 해결책
비디오를 실행시면서 낮은 해상도로 비디오를 인코딩한다. 
그래서 화면 수가 특정 개수를 넘어가면 기존에 있는 고해상도 영상과
만들어진 저해상도 영상을 스왑해서 실행시키면 될 거 같다.
